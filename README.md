## Projek UKK Paket empat Perpustakaan digital

### == Fitur Utama dalam Projek ==
**User:**
1. Login & Registrasi
> User dapat melakukan itu
2. Melakukan Transaksi
> User dapat meminjam buku yang tersedia, Pengembalian harus disertakan bukti Peminjaman di tab *Transaksi & Riwayat* kepada admin perpustakaan secara tatap muka, Lalu Admin akan menyatakan Transaksi pengembalian.


**Admin:**
1. Login
> Admin dapat melakukan login sebagai role admin
2. CRUD Kelola Anggota/User
> Admin dapat mengelola User di tab *Admin Menu > Kelola Anggota*. Admin dapat Mengubah, Menghapus, Menambah, bahkan menampilkan semua daftar user dengan total.
3. CRUD Kelola Buku
> Admin dapat mengelola koleksi buku, baik Menambah, Mengubah, Menghapus dan menampilkan semua total buku yang ada
4. CRUD Keloka Transaksi
> Admin dapat mengelola User ketika mereka melakukan transaksi (Peminjaman) lalu Admin bisa menyetujui peminjaman tersebut dan dapat menyatakan pengembalian buku.

**Fitur Lain**
1. Logout
2. Profile Saya
> Dapat melihat total Transaksi terkini dan melihat Username + ID User
